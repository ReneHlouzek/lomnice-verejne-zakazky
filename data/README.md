# Data

Sem bude crawler ukládat normalizovaná data a historické snapshoty.

- `index.json` – aktuální index zakázek a počty podle stavů
- `snapshots/` – časové snapshoty seznamu zakázek
- `projects/` – normalizované projektové záznamy
- `companies/` – dodavatelé a účastníci
- `changes/` – dodatky, změny cen a termínů
